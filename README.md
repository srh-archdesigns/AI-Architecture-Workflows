# AI Architecture Workflows

## About the Project

AI Architecture Workflows is an open-source initiative by SRH Architects & Designs focused on exploring artificial intelligence in architecture, civil engineering, BIM automation, and 3D architectural visualization.

## Project Goals

- AI-assisted 2D floor plan development.
- 3D architectural design and visualization workflows.
- Revit and BIM automation.
- AI-assisted interior and exterior design.
- Automated architectural documentation.
- AI agent workflows for architecture businesses.

## Technologies Under Exploration

- Python
- Autodesk Revit API
- AutoCAD
- AI and Large Language Models
- BIM Automation
- 3D Visualization Tools

## Vision

Our vision is to make AI-powered architectural workflows more accessible, efficient, and affordable for architects, civil engineers, students, and small design studios.
